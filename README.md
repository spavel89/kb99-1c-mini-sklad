# kb99-1c-mini-sklad
Стажировка КБ99
Данный репозиторий содержит материалы по стажировке в КБ99.
В папке КБ99 находятся файлы разрабатываемой конфигурации. Развернуть данную конфигугацию можно через конфигуратор (Конфигурация - Загрузить конфигурацию из файлов, указать неоходимый каталог с файлами).
